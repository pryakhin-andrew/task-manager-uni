## Запуск проекта

1. Скачайте архивный файл проекта и распакуйте:


2. Установите приложение для запуска php сервера, например ``MAMP``


3. Перенесите все файлы проекта в папку ``htdocs``<br>


4. Запустите локальный сервер, нажав кнопку start в приложении ``MAMP``


5. Откройте проект и настройте доступ к базе данных в
   файле [db.php](lib/db.php), пример для ``MySql``:
    ```php
    <?php
    $pdo = new PDO('mysql:host=localhost;dbname=php-website;port=8899', 'root', 'root');
    ```


6. Приложение будет доступно по адресу: http://localhost:8888.
